# Secret Solver v4.3 - Update Wizard (Canary)

> ⚠️ **Canary Release** — This version is available to canary testers only. App access is restricted to the canary channel.

## Latest Updates (v4.3 - Update Wizard)
- **Update Wizard**:
  - New step-by-step wizard guides you through the update process.
  - Clear on-screen instructions tell you exactly what to do at each stage.
  - 3D graphics to visualize each step are in the works — stay tuned for a future release once they're polished enough to ship.
- **Calculator Keepalive**:
  - Device now maintains an active connection with the calculator during updates.
  - Prevents the calc from timing out or disconnecting mid-update.
  - More reliable update experience overall.

---

## Previous Updates (v4.2 - Stability Update)
- **BLE Typing Fix**:
  - Resolved an issue where typing text to the calculator would fail after the first character.
  - Multi-character input now works reliably over BLE.
  - Improved key send/acknowledge handshake timing for consistent input delivery.
- **Reply Loading Fix**:
  - Fixed a bug where replies would get stuck in an infinite loading state.
  - Messages and replies now load consistently without requiring a restart.

## All Features
- **Secret Solver App** *(Canary Testers Only)*:
  - Companion app with full two-way communication with your device.
  - Access AI assistant, chats, and notes from your phone.
  - Canary-exclusive access during this release phase.
- **Update Wizard**:
  - Step-by-step guided update process with clear instructions.
  - 3D visual guidance coming in a future release.
- **Calculator Keepalive**:
  - Active connection maintained with the calculator during updates.
  - Prevents timeouts and disconnections mid-update.
- **BLE Communication Protocol**:
  - Bluetooth Low Energy connection between device and app.
  - Faster and more power-efficient than WiFi hotspot.
  - Seamless pairing experience.
- **Targeted Firmware Versioning**:
  - Channel-based update system for testers and regular users.
  - Tester channel receives early access to new firmware builds.
  - Regular users receive stable releases automatically.
- **Emergency Recovery System**:
  - Device reflash capability for manufacturing defect correction.
  - Security key regeneration support for technical assistance.
  - Comprehensive system recovery with data preservation.
  - Enhanced diagnostic and troubleshooting tools.
- **Notes Management**:
  - Access your complete notes library from your calculator.
  - Read full note content with advanced scrolling capabilities.
  - Request pairing codes for external note applications.
- **Advanced Scrolling System**:
  - Configurable scroll speeds for optimal reading experience.
  - Full page mode for rapid navigation through long content.
  - Persistent scroll preferences stored in device memory.
- **Secret Solver Chats**:
  - Private messaging between users with permanent usernames.
  - Public community chat connected to Discord.
  - Message history and conversation management.
  - User blocking and privacy controls.
- **AI Assistant**:
  - Smooth scrolling interface with proper formatting.
  - Chat history system with up to 50 saved conversations.
  - DIRA mode for direct, concise answers.
  - Natural conversation flow with follow-up support.
- **Enhanced Web Configuration**:
  - Complete device setup through intuitive web interface.
  - Password management and WiFi setup.
- **Program Library**:
  - Download useful calculator programs wirelessly.
  - Browse a growing collection of math and utility programs.
